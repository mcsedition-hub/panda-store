## Using Panda Store

[Installation](installation.md) explains how to run Panda Store, choose English or French,
and start from an idea, an imported app or a demo.

[Connections](connections.md) covers App Store Connect, Google Play and AI providers.

[AI usage](ai-usage.md) explains token tracking, estimated costs, budgets and provider balances.

[ASO](aso.md) covers listing proposals from an idea, saved audits, model comparisons,
screenshot reviews and editable drafts.

[SMM](smm.md) covers browser research, saved sessions, reference filters,
one to three adaptations, scripts, scenes and exports.

## Development

The [development guide](development.md) lists configuration and checks.
The [module guide](modules.md) explains how to extend Panda Store.
The [architecture](architecture.md) describes the application and its workflows.
Repository documentation is maintained in English. The main introduction also has
a [French version](../README.fr.md); the application supports both languages.

See the [roadmap](roadmap.md) for planned work and release validation,
and the [ASO evaluation](aso-evaluation.md) for research and review methods.
